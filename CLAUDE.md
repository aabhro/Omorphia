**For every UI task, read the component catalog first.** Identify each matching Omorphia custom element and inspect its source before coding. Never guess APIs or build a duplicate control. Do not author raw native buttons, inputs, selects, date/time widgets, checkbox/radio/switch/range controls, or details accordions in app markup. Use the custom elements. Keep menus, popovers, drawers, and picker panels borderless and reuse the shared morph motion.

These files are mandatory project context. Read and follow them before acting. For UI work, inspect the complete, publicly accessible Modernimal stylesheet, component reference, and motion system in `aabhro/Stylesheets`.
